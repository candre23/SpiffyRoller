UNIVERSAL DICE SET FORMAT V1
============================

Runtime location
----------------
Each set is a folder directly inside:

    /storage/templates/

The folder must contain:

    set.json

Example:

    /storage/templates/my_set/set.json
    /storage/templates/my_set/icons/success.bmp

Discovery
---------
The firmware scans each immediate child folder of /storage/templates during
normal startup. Invalid folders are ignored and reported to the serial log.
The built-in Standard set is always available as index zero.

Manifest identity
-----------------
Required top-level fields:

    "format": "universal-dice-set"
    "format_version": 1
    "id": stable identifier using letters, numbers, underscore, or hyphen
    "name": user-facing set name
    "dice": array of die definitions

Current firmware limits
-----------------------
- 16 total sets including Standard
- 16 die types per custom set
- 64 faces per die
- 64 KiB maximum set.json size
- relative asset paths only
- duplicate set IDs are rejected

Die colors
----------
Every die declares defaults:

    "body_color": "#163A5F"
    "ink_color": "#FFFFFF"

These defaults apply to every face unless that face overrides one or both:

    {
      "image": "icons/special.bmp",
      "image_mode": "mask",
      "body_color": "#7A1022",
      "ink_color": "#FFD84D"
    }

Face artwork modes
------------------
Each face independently chooses its artwork type.

Text or numeric face:

    {"value": 4, "label": "4"}

Current firmware artwork support
--------------------------------
BMP artwork is now implemented. Use uncompressed BMP files:
- 1-bit BMP recommended for mask artwork
- 4-bit indexed BMP recommended for multicolor artwork
- 8-bit, 24-bit, and 32-bit uncompressed BMP also load

Mask convention:
- black pixels are treated as transparent
- light pixels are drawn using the face ink_color

Indexed convention:
- palette/indexed colors are preserved
- pure black is treated as transparent

Tintable monochrome mask:

    {
      "image": "icons/success.bmp",
      "image_mode": "mask"
    }

Multicolor indexed artwork:

    {
      "image": "icons/special.png",
      "image_mode": "indexed"
    }

Mask and indexed faces may be mixed freely on the same die. A mask uses the
effective ink color for that face. Indexed artwork uses colors stored in its
own palette. A face may still override body_color when using indexed artwork.

Image recommendations
---------------------
Mask:
- indexed PNG with two palette entries
- transparent background plus one opaque ink entry
- recommended 48x48
- maximum planned runtime size 64x64

Indexed:
- indexed PNG
- maximum 16 palette entries including transparency
- recommended 48x48
- maximum planned runtime size 64x64

Milestone status
----------------
Version 22 implements:

- folder discovery
- manifest parsing
- structural validation
- color and artwork-mode validation
- per-die defaults
- per-face color overrides
- mixed mask/indexed declarations
- persistent set selection
- Set selection submenu

Version 22 deliberately does not yet render custom dice or execute custom
rules. Selecting a custom set validates and persists it, but rolling is blocked
with a notice until the custom-dice runtime milestone is installed.
