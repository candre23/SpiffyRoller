Spiffy Roller

Browser-based firmware installer for the Waveshare ESP32-S3-Touch-AMOLED-1.8.

Firmware installer

This browser does not support Web Serial. Use current desktop Chrome or Microsoft Edge.Firmware installation requires this page to be served over HTTPS.
Supported hardware only: Waveshare ESP32-S3-Touch-AMOLED-1.8. Installing this firmware on another board may leave it unusable until reflashed with compatible firmware.

Installation

  1. Connect the module to the computer using USB-C.
  2. Put it into download mode by holding BOOT, briefly pressing PWR, then releasing BOOT.
  3. Select the firmware version above.
  4. Click Install Spiffy Roller.
  5. Select the ESP32 serial port when prompted.
  6. Confirm the installation and wait for the module to restart.

A first-time installation erases device flash. Copy custom dice sets back afterward using Spiffy Roller USB storage mode.
